# Self Review

## Trace the Decision

Treat a result from `mentat` as evidence about the instructions that produced it. Identify the choice and the instruction that governed it. Apply the same tests for intent, scope, and authority to that instruction.

If the agent had enough guidance, correct the work. If the guidance arrived too late, check its trigger. Correct the trigger or its link if it caused the delay. If a different rule would change the choice, keep only the missing condition, action, or exception.

## Scope the Change

Check whether the same decision applies in another project. Keep project rules in their project guides. If `mentat` repeats a project rule, propose removing the copy from this skill. Put a rule in `SKILL.md` only when each use needs it. Put other rules in the relevant reference with a direct link from `SKILL.md`.

Use evidence to propose changes to this skill. Apply them within the authority the human gave you. Preserve human approval for constitutional changes.

## Recheck and Stop

For a change in behavior, run the same case before and after the edit. Check a nearby case that should keep its result. If the change affects another instruction, check that instruction with the same method.

Stop when no further change would affect a future decision. If evidence or approval is missing, state what you need.
